记录各种编码的作用和起源

<!--more-->

| 编码/字符集     | 作用说明                                                 |
|------------------|----------------------------------------------------------|
| ASCII            | 英文和基础字符；用于早期计算机和协议                     |
| Unicode（UTF-8） | 支持全球所有语言，现代标准编码                           |
| UTF-16 / UTF-32  | 多语言支持，适合内部处理                                  |
| GB2312/GBK/Big5  | 中国大陆 / 台湾 / 香港地区旧编码标准                      |
| Emoji / U+1Fxxx  | 表情符号（属于 Unicode 的一部分）                         |
| 控制字符（U+0000 ~ U+001F）| 表示“换行”“回车”等控制行为，不是可见字符 |

## html中的编码

| 影响维度 | lang="zh-Hans" 的具体作用 |
|----------|------------------|
| 字体渲染 | 使用简体专用字体（如 PingFang SC） |
| 输入法候选词 | 优先显示简体词汇 |
| 屏幕阅读器语音 | 使用简体中文语音合成 |
| SEO 匹配 | 给简体用户优先展示 |
| 标点排版 | 使用简体中文格式习惯 |
| 拼写检查 | 使用简体中文词典 |
